# 🚒 Новости МЧС для Home Assistant

**Всё в одном**: интеграция создаёт сенсоры новостей и добавляет готовую карточку для дашборда.

## 🔥 Особенности

- ✅ Установка через HACS (одним кликом)
- ✅ Настройка через UI (без редактирования YAML)
- ✅ Автоматическое создание сенсоров (1-5 штук)
- ✅ Готовая карточка с прокруткой и визуальным редактором
- ✅ Отображение заголовка, описания, даты и картинок
- ✅ Полностью на русском языке

## 📦 Установка

### Через HACS (рекомендуется)

1. Зайдите в HACS → три точки → **Пользовательские репозитории**
2. Добавьте: `https://github.com/NagibinA/novosti_mchs` (тип: **Интеграция**)
3. Нажмите "Установить" и перезагрузите Home Assistant

### Вручную

1. Скопируйте папку `custom_components/novosti_mchs` в `/config/custom_components/`
2. Перезагрузите Home Assistant

## ⚙️ Настройка

1. Зайдите в **Настройки → Устройства и службы**
2. Нажмите **Добавить интеграцию** → найдите **Новости МЧС**
3. Введите URL RSS-ленты (по умолчанию стоит лента МЧС)
4. Укажите количество сенсоров (1-5)
5. Нажмите **Создать**

После этого появятся сенсоры: `sensor.novosti_mchs_1`, `sensor.novosti_mchs_2` и т.д.

## 📰 Добавление карточки

1. На вашем дашборде нажмите **Добавить карточку**
2. Найдите **Новости МЧС** в списке
3. В настройках выберите сенсор и настройте отображение

Или добавьте вручную через YAML:

```yaml
type: custom:news-mchs-card
entity: sensor.novosti_mchs_1
title: 📰 Оперативная информация
max_articles: 15
show_description: true
show_date: true
show_image: true
card_height: 450
